Value Classes Still Need Compiler Sympathy

Declaração de uma classe de valor é, acima de tudo, uma decisão semântica. Isso diz aos outros programadores que as instâncias dessa classe são definidas inteiramente por seu estado e não precisam de identidade. Esse modelo mais claro é valioso em si mesmo! A liberdade adicional do JVM para otimizar como essas classes são representadas é um bônus acolhido. O C2 pode fazer coisas incríveis com essa liberdade, mas não consegue sempre recuperar informações escondidas atrás das fronteiras de abstração. Aprofundamento e inspeção do código gerado permanecem as melhores opções...
